# Правила проекта Terminals

## Документация проекта
Входной набор (читать до первого действия): этот файл · `docs/INDEX.md` · `memory/MEMORY.md` · `memory/new-session-prompt.md`. Ничего сверх этого перечня во входе нет.

## Правила
- `memory/` — временное хранилище (отчёты агентов, черновики), в git не попадает; решения, инварианты и правила туда не кладутся, их место — `docs/`.
- Документация хранится в каталоге проекта, а не в глобальной памяти `~/.claude/projects/`: это исключение из правила маршрутизации хранилища, проект не относится к Vigbo.
