# Правила проекта Terminals

## Документация проекта
Входной набор (читать до первого действия): этот файл · `docs/INDEX.md`. Ничего сверх этого перечня во входе нет. `memory/MEMORY.md` и `memory/new-session-prompt.md` (открытые вопросы владельцу, незавершённая работа) читать, только когда задача их касается или владелец просит продолжить прошлую работу.
Порядок: прочитать `docs/INDEX.md`, затем только файлы под текущую задачу. Целиком документацию не читать.
Изменил поведение кода, описанное в `docs/` (механика, ограничение, команда, схема БД), — в том же коммите обновить соответствующий файл. Порядок ведения — `docs/rules_documentation.md`.
Проверка документации: `~/.claude/check-docs.sh /media/user/H_SSD_33/projects/terminals`.

## Правила
- `memory/` — временное хранилище (отчёты агентов, черновики), в git не попадает; решения, инварианты и правила туда не кладутся, их место — `docs/`.
- Документация хранится в каталоге проекта, а не в глобальной памяти `~/.claude/projects/`: это исключение из правила маршрутизации хранилища, проект не относится к Vigbo.
