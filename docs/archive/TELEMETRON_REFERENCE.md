# Telemetron — справочник по функционалу

Источник: https://my.telemetron.net/ (демо-доступ)
SaaS-платформа для удалённого мониторинга и управления вендинговыми автоматами.
200 000+ подключённых устройств, 17+ стран. ООО "Делориан", с 2013 года.

## 1. Структура навигации

Основные разделы ЛК:
- Обзор (Dashboard)
- Автоматы (список + карточка каждого)
- Продажи / Статистика
- Отчёты (10+ типов)
- Настройки (пользователи, рецептуры, планограммы, локации, уведомления)
- Модемы (оборудование связи)

Мобильное приложение Teleport (Flutter, iOS + Android):
- Таббар: Дашборд / Автоматы / События / Профиль
- Сканер штрихкодов для быстрого доступа к автомату
- Загрузка товаров и инвентаризация
- Критические уведомления

---

## 2. Dashboard (обзор)

Сводная информация по всей сети автоматов:
- Статусы автоматов в реальном времени: работает / не работает / нет связи
- Динамика продаж за 7 / 14 / 30 дней (график)
- Последние события системы (ошибки, обслуживания)
- Эффективность работы сети (процент uptime)
- Сервисные флаги:
  - `low_change` — мало сдачи
  - `need_loading` — нужна загрузка ингредиентов
  - `no_recent_sales` — нет продаж (автомат может быть неисправен)
  - `no_bills_in` — нет купюр
  - `no_coins_in` — нет монет

## 3. Автоматы

### 3.1. Список автоматов

Настраиваемый дашборд с колонками:
- Серийный номер, имя, тип (кофе / снэк / комбо / другое / парный / банка)
- Состояние: 0=неизвестно, 1=работает, 2=не работает, 3=нет GSM
- IMEI модема, уровень GSM-сигнала
- Привязанная планограмма
- Локация установки
- Теги для группировки (по региону / оператору / типу)
- Инвентарный номер
- Геотеги (координаты)

Фильтрация и сортировка по любой колонке. Поиск по имени/серийному номеру.

### 3.2. Карточка автомата (вкладки)

**Обзор**
- Общий доход за период
- Дата/время последней продажи
- Дата/время последнего обслуживания
- Дата/время последней инкассации
- Время последней загрузки ингредиентов
- Время последнего полученного отчёта от автомата

**Продажи в реальном времени**
- Лента продаж с платёжной шины автомата
- Тип оплаты (наличные / безналичные / токены)
- Название продукта, цена, время

**Ошибки и события**
- Коды ошибок с уровнями severity (critical / warning / info)
- История событий до 14 дней
- Типы: потеря связи, ошибка выдачи, переполнение монетоприёмника, замятие купюры, ошибка температуры и т.д.

**Загрузка / Остатки**
- Текущий уровень загрузки по каждому компоненту (визуальный прогресс-бар)
- Критический уровень (настраивается в планограмме)
- История загрузок с обнаружением недозагрузки (ожидали X, загрузили Y)
- Прогноз: через сколько дней закончится компонент (на основе темпа продаж)

**Инвентаризация**
- Абсолютные значения остатков (не дельта)
- Фиксация реальных остатков при обслуживании
- Расхождения между ожидаемым и фактическим

**Денежный ящик**
- Количество и номиналы купюр
- Количество и номиналы монет
- Сумма для сдачи
- История инкассаций

**Расходы** (функция 2025-2026)
- Административные расходы
- Аренда локации
- Текущие расходы (обслуживание, расходники)
- Учитываются в отчётах по прибыльности

**Настройки автомата**
- Параметры модема
- Параметры платёжных систем
- Привязка к планограмме

**Отчёты EVA-DTS**
- Аудиторские отчёты в формате DEX/DDCMP
- Стандарт вендинговой индустрии для учёта

### 3.3. Действия с автоматом

- Создание нового автомата
- Редактирование настроек
- Перезагрузка модема (удалённо)
- Запрос данных с автомата (отчёт / конфигурация)
- Загрузка товара (дельта-загрузка: сколько добавлено)
- Инвентаризация (абсолютные значения: сколько сейчас на самом деле)
- Выдача напитка (для совместимых моделей, например Jofemar G23)
- Пополнение кредита через Vendista

## 4. Продажи / Статистика

### 4.1. Сводка продаж
- За произвольный период: количество, сумма (общая и по каждому автомату)
- Фильтры: по автомату, группе, локации, типу оплаты

### 4.2. Таймлайн продаж
- Хронологический список всех продаж по всем автоматам
- Каждая запись: время, автомат, продукт, цена, тип оплаты

### 4.3. Аналитика по продуктам
- Продажи по каждому продукту: время, ячейка, имя, тип (платные / бесплатные / тестовые), цена, количество, сумма
- Фильтры: скрытие ненужных столбцов/продуктов, показ удалённых автоматов

### 4.4. Продажи по типу оплаты
- Наличные / безналичные / токены — с разбивкой по продуктам
- Общая сумма и количество по каждому типу

### 4.5. ТОП продаж
- Рейтинг самых популярных позиций за период
- Количество, сумма, доля от общих продаж (%)

## 5. Отчёты

10+ типов отчётов с экспортом в CSV и Excel:

### 5.1. Отчёт по автоматам
- Выручка за период
- Маржинальность (выручка минус себестоимость ингредиентов)
- Прибыль (минус расходы: аренда, обслуживание, расходники)
- Сравнение автоматов между собой

### 5.2. Финансовые отчёты
- По периоду, автоматам, группам, продуктам, арендодателям
- Детализация до каждой транзакции

### 5.3. Отчёт по инкассациям
- Когда и сколько собрано из каждого автомата
- Наличные по номиналам

### 5.4. Отчёт по обслуживаниям
- Кто, когда, какой автомат обслуживал
- Что было сделано (загрузка, чистка, ремонт)

### 5.5. Отчёт по событиям/ошибкам
- Группировка по типу ошибки, автомату, периоду
- Severity: critical / warning / info

### 5.6. Отчёт по кассовым чекам (фискальные данные)
- Данные от ККТ (OrangeData, CheckOnline, Initpro)
- Массовая переотправка чеков при ошибках

### 5.7. Отчёт по загрузкам ингредиентов
- По оператору / автомату / группе
- Сколько загружено каждого компонента
- Обнаружение недозагрузки

### 5.8. Суточные проверочные отчёты
- Автоматическая ежедневная сверка данных

### 5.9. Отчёт по остаткам (функция 2025-2026)
- Остатки на дату по всем автоматам
- Поячеечная детализация
- Сравнение ожидаемых и фактических остатков

### 5.10. Отчёт по продуктам с детализацией прибыли (функция 2025-2026)
- Себестоимость каждого продукта
- Прибыль по продукту
- Доля прибыли от общей

### 5.11. Коррекционные чеки
- Исправление ранее выбитых фискальных чеков

## 6. Настройки

### 6.1. Пользователи и роли
- Создание/удаление пользователей
- Кастомизируемые роли с гранулярными правами:
  - Биллинг и данные компании
  - Управление пользователями / группами / ролями
  - Настройка планограмм, продуктов, рецептур
  - Локации автоматов
  - Финансовые отчёты
  - Информация о товарах и сотрудниках
  - Продажи и обслуживание
  - Настройки автоматов и модемов
  - Расчёт прибыли
  - Просмотр прибыли и расходов
- Доступ к конкретным автоматам (все или выборочно)

### 6.2. Рецептуры / Продукты
- Простые продукты (один компонент) и составные рецепты (несколько ингредиентов)
- Компоненты/ингредиенты: единицы измерения (мл, шт, г)
- Себестоимость за единицу или за упаковку с автоматическим пересчётом
- Привязка рецептуры к продукту → автоматическое списание ингредиентов по продажам
- Признак предмета расчёта (товар / услуга) для фискализации

### 6.3. Планограммы
- Создание / удаление / привязка к автоматам
- Режимы: snack (ячейки с физическими товарами) / basic (ингредиенты для приготовления)
- Каждая ячейка: продукт, ёмкость (максимум), критический уровень (при каком остатке отправлять уведомление)
- Автоматическое списание ингредиентов по продажам (на основе рецептуры)

### 6.4. Локации
- Имя, адрес, заметки
- Привязка автоматов к локации
- CRUD-операции

### 6.5. Уведомления
Каналы доставки:
- Email
- SMS
- Telegram

Типы уведомлений:
- Ошибки автомата (по severity)
- Потеря связи (автомат не выходит на связь N минут)
- Критический уровень остатков (ингредиент ниже порога)
- Инкассация выполнена
- Обслуживание выполнено

Настройка: по конкретному автомату или по группе.

### 6.6. Реквизиты компании
- Данные для ККТ: OrangeData, CheckOnline, Initpro
- Несколько юридических лиц в одном аккаунте
- Переключение между аккаунтами компаний

### 6.7. Мастер быстрой настройки
- Пошаговая настройка основных возможностей ЛК для новых пользователей

## 8. API (v2)

Base URL: `https://api.telemetron.net`
Авторизация: OAuth2 (grant_type: password, auth_code, refresh_token)
Формат: JSON, ISO-8601 timestamps (UTC, поддержка `local=1` для локального времени)

### Ключевые эндпоинты

**Авторизация**
- `POST /auth/` — получение токена
- `GET /logout` — выход
- `GET /v2/me` — текущий пользователь
- `GET /v2/requisites` — реквизиты компании

**Автоматы**
- `GET /v2/vending_machines` — список
- `GET /v2/vending_machines/{id}` — детали
- `POST /v2/vending_machines` — создание
- `PUT /v2/vending_machines/{id}` — обновление
- `GET /v2/vending_machines/{id}/events` — события (до 14 дней)
- `GET /v2/vending_machines/{id}/reports` — отчёты EVA-DTS
- `POST /v2/vending_machines/{id}/reset` — перезагрузка модема
- `POST /v2/vending_machines/{id}/dispense` — выдача напитка
- `POST /v2/vending_machines/{id}/vendista-credit` — кредит через Vendista
- `GET /v2/vending_machines/{id}/loading` — текущая загрузка
- `POST /v2/vending_machines/{id}/loading` — загрузка товара (дельта)
- `GET /v2/vending_machines/{id}/loading_tx` — история загрузок
- `POST /v2/vending_machines/{id}/inventory` — инвентаризация

**Продажи и статистика**
- `GET /v2/stats/vends/summary` — сводка
- `GET /v2/stats/vends/payments/summary` — по типам оплаты
- `GET /v2/vending_machines/{id}/stats/vends/summary` — продажи автомата
- `GET /v2/vending_machines/{id}/stats/vends/products` — по продуктам
- `GET /v2/vending_machines/{id}/stats/vends/payments` — по оплатам

**Отчёты**
- `GET /v2/reports/collections` — инкассации
- `GET /v2/stats/crt` — фискальные чеки
- `GET /v2/stats/crt/correction` — коррекционные чеки

**Справочники**
- `GET /v2/planograms` — планограммы (CRUD)
- `GET /v2/products` — продукты (CRUD)
- `GET /v2/products/{id}/components` — компоненты рецепта (CRUD)
- `GET /v2/components` — ингредиенты (CRUD)
- `GET /v2/locations` — локации (CRUD)
- `GET /v2/event_codes` — коды событий
- `GET /v2/vm_models` — модели автоматов
- `GET /v2/timezones` — часовые пояса

## 11. Пересечения с проектом Terminals

| Функция Telemetron | Аналог в Terminals | Статус |
|---|---|---|
| Список автоматов + статус | Список точек обслуживания | Этап 2 (не начат) |
| Загрузка ингредиентов | Запись "Принёс" при обслуживании | Этап 3 (не начат) |
| Остатки ингредиентов | Учёт остатков по точкам | Этап 7 (после MVP) |
| Продажи (через Vendista API) | Интеграция с Vendista API | Частично (сервис создан) |
| Обслуживание | Запись обслуживания (фото, вода, комментарий) | Этап 3 (не начат) |
| Уведомления (email, SMS, Telegram) | Уведомления через Telegram | Этап 10 (после MVP) |
| Рецептуры | Рецептуры | Этап 11 (после MVP) |
| Планограммы | Нет прямого аналога | — |
| Локации | Точки с координатами | Этап 2 (не начат) |
| Роли и права | admin / operator | Этап 1 (реализован) |
| ККТ / фискализация | Не планируется | — |
| Модемы / телеметрия | Не планируется (нет оборудования) | — |
| Расходы / прибыльность | Не планируется в MVP | — |
